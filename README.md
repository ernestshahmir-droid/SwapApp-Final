# SwapApp: Peer-to-Peer Skill Exchange

A native Android application engineered to facilitate peer-to-peer service trading. Instead of traditional currency, users exchange skills and services using a custom virtual time-credit system.

## 🚀 Core Features
* **Time-Credit Wallet:** Custom transaction logic that securely tracks, deducts, and awards virtual time balances upon task completion.
* **Skill Marketplace:** Dynamic user interfaces allowing users to browse, list, and negotiate skill exchanges locally.
* **Offline Persistence:** Local database caching ensures core functionalities and wallet balances remain accessible without continuous internet access.
* **Real-Time Infrastructure:** Cloud connectivity to manage user states and platform data.

## 🛠️ System Architecture & Engineering
This application was developed following Agile methodologies and rigorous software engineering lifecycles:
* **System Modeling:** Architected using comprehensive Unified Modeling Language (UML) diagrams (Class, Component, and Use Case) alongside Data Flow Diagrams (DFD Levels 0, 1, and 2).
* **Testing & QA:** Quality assurance managed through structured User Acceptance Testing (UAT) and execution steps tracked via Zephyr test cycles.
* **Project Management:** Iterative development driven by Sprint backlogs, user stories, Epics, and burndown charts maintained in Jira.

## 💻 Tech Stack
* **Language:** Java (Android SDK)
* **UI/Layout:** XML, Material Design
* **Local Database:** SQLite 
* **Backend:** Firebase 
* **IDE:** Android Studio
